# PortIQ Prototype README

## Product

**PortIQ -- AI-Powered Portfolio Intelligence**

## Overview

PortIQ is an AI-powered portfolio decision intelligence prototype
developed as part of the MBA Capstone for the *Management of AI
Products* course. The prototype demonstrates how AI can augment
portfolio management by combining deterministic business calculations
with evidence-grounded AI responses.

## Prototype Scope

The MVP includes: - Executive Dashboard - Portfolio Analysis - Clients -
Projects - Reports - PortIQ Copilot

The prototype demonstrates the end-to-end workflow from portfolio review
to AI-assisted decision support.

## Technology Stack

-   React
-   Vite
-   Tailwind CSS
-   Recharts
-   JavaScript
-   Vercel Serverless Function (prototype)
-   Large Language Model (API-based orchestration)

## AI Role

The AI Copilot interprets verified portfolio metrics and generates
business insights. It does not modify data or make autonomous business
decisions. All recommendations are intended to support human decision
making.

## Current Limitations

-   Uses synthetic demonstration data
-   No live enterprise integrations
-   No predictive forecasting
-   Requires an LLM API for live AI responses
